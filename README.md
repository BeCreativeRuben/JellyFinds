# JellyFinds

A Next.js storefront for decorative tech — lamps, quiet speakers, and playful objects for living rooms, bedrooms, and desks.

## Local

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Vercel

This app is a standard Next.js App Router project. Import the GitHub repo in the [Vercel dashboard](https://vercel.com/new) or run:

```bash
npx vercel
```

No environment variables are required for the catalogue, bag, or demo checkout.
